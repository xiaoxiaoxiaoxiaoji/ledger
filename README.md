# 📒 每日记账 · 使用说明（保姆级）

一个**打开就能用**的小账本：手机、电脑都能记，分类、月度统计、预算提醒、导出 Excel 全都有。
不需要安装任何软件，不需要懂代码。跟着下面做就行。

---

## 一、最快上手：不联网也能用（本地模式）

1. 把整个文件夹放到你喜欢的位置（比如桌面）。
2. 双击打开里面的 **`index.html`**，会用浏览器（推荐 Chrome / Edge / Safari）打开。
3. 直接在「记一笔」里输入金额、选分类、点保存即可。

> ⚠️ 本地模式下，数据只存在**当前这台电脑的这个浏览器**里。
> 想手机和电脑记同一份账，需要看下面「第二步」配置云端同步。

---

## 二、配置云端同步（让手机、电脑看到同一份账）

原理：用一个免费的云数据库（Supabase）存你的账，只要用**同一个邮箱登录**，手机和电脑打开就是同一份数据。
全程约 5 分钟，只需要做一次。

### 第 1 步：注册 Supabase 免费账号

1. 打开浏览器，访问 **https://supabase.com**
2. 点右上角 **"Start your project"**，用 GitHub 或邮箱注册（免费）。
3. 登录后进入后台，点 **"New Project"** 新建一个项目。

### 第 2 步：创建项目

- **Name**：随便填，比如 `myleger`
- **Database Password**：设一个密码（记下来，后面用不到但别丢）
- **Region**：选离你近的，比如 `Northeast Asia (Tokyo)`
- 点 **"Create new project"**，等待 1~2 分钟初始化完成。

### 第 3 步：复制两个关键信息

项目建好后，左下角点 **⚙️ Settings（设置）→ API**，你会看到：

- **Project URL**：形如 `https://abcd1234.supabase.co` → 复制它
- **Project API keys → anon public**：一长串字母数字 → 复制它

用记事本把这两个值填到本文件夹的 **`js/config.js`** 里：

```js
window.APP_CONFIG = {
  supabaseUrl: "https://abcd1234.supabase.co",        // ← 粘贴 Project URL
  supabaseKey: "eyJhbGciOi...很长一串...",             // ← 粘贴 anon public key
  supabaseSdkUrl: "https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2/dist/umd/supabase.min.js"
};
```

### 第 4 步：建数据库表（一次性）

1. 在 Supabase 后台左侧菜单点 **"SQL Editor"** → 点 **"New query"**。
2. 用记事本打开本文件夹里的 **`sql/supabase_schema.sql`**，**全部复制**里面的内容，粘贴到编辑框。
3. 点右下角绿色 **"Run"** 按钮。看到绿色提示 **"Success"** 就完成了。

### 第 5 步：开启邮箱登录（一般已默认开启）

1. 后台点 **Authentication → Providers**。
2. 确认 **Email** 这一行是 **Enabled**（开关打开）。
3. 建议把 **"Confirm email"** 关掉（关掉后注册即用，不用去邮箱点确认链接）。

### 第 6 步：注册账号并登录

1. 双击打开 `index.html`。
2. 点右上角 **"登录同步"** → 「点此注册」→ 输入你的邮箱和一个至少 6 位的密码 → 注册。
3. 如果上一步没关 Confirm email，去邮箱点确认链接，再回来登录。
4. 登录成功后，右上角会变成绿色圆点 + 你的邮箱，之后记的每一笔都会自动存到云端。

## 三、把应用放到网上，让手机和电脑都能打开

你现在的 `index.html` 是放在自己电脑上的一个文件，手机访问不到它。要让手机也能打开，
需要把这整个文件夹**免费托管到网上**。推荐用拖拽式托管，全程不用敲命令。

### 方案 A：Netlify Drop（最简单，推荐）

1. 打开 **https://app.netlify.com/drop**
2. 把**整个文件夹**（包含 index.html 的那个）直接拖到网页中间的虚线框里。
3. 等几秒钟，它会给你一个网址，形如 `https://random-name-123.netlify.app`。
4. 把这个网址**发到自己微信文件传输助手 / 收藏**，手机和电脑都能打开。
5. 打开后用**同一个邮箱登录**，两边就是同一份账。

> 想改个好记的网址：Netlify 后台 → Site configuration → Change site name。

### 方案 B：GitHub Pages（备选）

1. 注册 github.com 账号，新建一个仓库（比如叫 `ledger`）。
2. 把文件夹里的所有文件上传到仓库。
3. 仓库 **Settings → Pages** → Source 选 `main` 分支 → Save。
4. 稍等片刻会得到 `https://你的用户名.github.io/ledger/` 网址。

### 方案 C：临时应急——直接把文件发给自己

不方便托管时，也可以把整个文件夹发到手机（微信/邮件），在手机上用浏览器打开 `index.html`。
但**这种方式手机和电脑数据不互通**，只适合临时用。要多端同步，请用方案 A 或 B。

## 四、手机添加到桌面（像 App 一样用）

- **安卓 Chrome**：打开网址 → 右上角 `⋮` 菜单 → **"添加到主屏幕"**。
- **iPhone Safari**：打开网址 → 底部 **分享按钮** → **"添加到主屏幕"**。
- **电脑 Chrome**：打开网址 → 地址栏右侧会出现一个「安装」小图标，点一下即可。

添加后桌面会出现一个「记账」图标，点开就是全屏应用，和原生 App 体验几乎一样。
在有网的环境打开过一次后，**没网也能打开看账本、记新账**（联网后自动同步）。

## 六、常见问题

**Q：我在手机上记的账，电脑上看不到？**
A：确认两边都是用**同一个邮箱登录**的（右上角绿色圆点旁会显示邮箱）。本地模式下数据是分开的。

**Q：断网了还能记账吗？**
A：能。没网时会先存在本机，联网后打开应用会自动把本机的账合并到云端。

**Q：导出的 CSV 用 Excel 打开是乱码？**
A：不会，文件已带 UTF-8 BOM，Excel 双击直接打开就是正常中文。

**Q：忘记密码怎么办？**
A：Supabase 后台 Authentication → Users 里可以重置。

**Q：我不想用云端了，数据会丢吗？**
A：退出登录后，本机已有的数据还在；云端的数据在 Supabase 里也不会自动删。
